# 设计样式目录

本目录收录来自 [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) 的 `DESIGN.md` 样式索引与常用样本。

- `index.json`：84 个风格的元数据、所属类别、预览链接和是否内置
- `<slug>/DESIGN.md`：内置的 16 个常用风格，可直接作为设计基线
- `LICENSE`：上游 MIT 许可证

内置风格：Claude、Cohere、ElevenLabs、Cursor、Linear、Vercel、Raycast、Notion、Cal.com、Mintlify、Figma、Framer、Stripe、Coinbase、Airbnb、Apple。

## 选择流程

1. 用户未指定样式时，先按四类视觉气质让用户选择：技术／产品感、简洁／效率感、创意／视觉感、大胆／品牌感。上游的行业分类只作为元数据，不作为一级选择。
2. 在所选类别中推荐 3–4 个具体风格，说明气质、适用场景、取舍和预览链接。
3. 用户也可以直接给出品牌名、slug 或参考网站。
4. 选中后，以对应 `DESIGN.md` 作为实现和验收基线；未内置的 slug 经用户确认后再获取。
5. 不一次性列出全部 84 个样式，不把预览链接当作已审核的设计规范。

样式文件来自上游项目，按其 MIT 许可证使用；本项目未对原始样式分析内容作实质修改。
